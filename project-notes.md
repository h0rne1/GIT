# Заметки по проекту

## Почему выбрана эта тема

Учёт складских товаров — простая и понятная предметная область: есть сущность
«товар», есть операции прихода/расхода, есть отчётность по остаткам. Такая
предметная область хорошо ложится на консольное приложение для начального
этапа курса (Git) и легко расширяется до REST API + БД на следующих этапах
(Docker, Docker Compose, Архитектура).

## План разработки

1. Инициализация репозитория, стартовые файлы (README, заметки, план API).
2. Скелет проекта: зависимости, структура каталогов.
3. Модель товара (`Item`) и JSON-хранилище остатков.
4. CLI-команды: добавление, удаление, просмотр списка товаров.
5. Отчёт по товарам с низким остатком.
6. Тесты для модели.

## Планируемые ветки

- `feature/inventory-model` — модель товара + хранилище остатков.
- `feature/cli` — CLI-команды `add` / `remove` / `list`.
- `feature/reports` — отчёт по товарам с низким остатком.
- `feature/docs` — обновление документации в README.

Ветки `feature/reports` и `feature/docs` создаются от одной и той же точки в
`main`, поэтому при слиянии обеих в `main` ожидается конфликт в README.md —
это сделано намеренно, чтобы отработать разрешение конфликтов (см.
`git-conflict.md`, который появится после того, как конфликт будет решён).
