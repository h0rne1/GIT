# План API (будущая версия)

Текущая версия проекта — консольное приложение (CLI). Ниже приведён план REST
API, который планируется реализовать на следующих этапах курса (после Docker
и Docker Compose), когда проект будет обёрнут в веб-сервис.

## Ресурсы

### Товары (Items)

- `GET /api/items` — получить список всех товаров.
- `GET /api/items/{sku}` — получить товар по SKU.
- `POST /api/items` — добавить новый товар.
- `PUT /api/items/{sku}` — обновить данные/количество товара.
- `DELETE /api/items/{sku}` — удалить товар со склада.

### Отчёты (Reports)

- `GET /api/reports/low-stock` — список товаров с остатком ниже минимального
  порога.

## Формат данных

Пример объекта `Item` в формате JSON:

```json
{
  "sku": "A1",
  "name": "Болты М6",
  "category": "Крепёж",
  "quantity": 120,
  "min_quantity": 20
}
```

## Аутентификация

На первом этапе — без аутентификации (учебный проект). В дальнейшем
планируется добавить API-ключ или JWT.

## Дальнейшее развитие

- Обернуть текущую CLI-логику (`src/`) в веб-фреймворк (Flask или FastAPI).
- Подключить БД вместо JSON-файла (SQLite/PostgreSQL).
- Описать `Dockerfile` и `docker-compose.yml` для сервиса и БД (следующие
  этапы курса).
