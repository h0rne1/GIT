# Описание конфликта и его решения

## Где возник конфликт

Конфликт возник в файле `README.md`, в разделе «Функциональность», в строке
чек-листа про отчёты по остаткам.

Ветка `feature/reports` изменила строку на:

```
- [x] Отчёты по остаткам (команда `report`)
```

Ветка `feature/docs` (создана от той же точки в `main`, что и
`feature/reports`) независимо изменила ту же строку на:

```
- [x] Отчёты по остаткам — реализован подробный отчёт по низким остаткам
```

и дополнительно добавила в README новый раздел «Технологии».

## Как был обнаружен конфликт

1. Ветка `feature/docs` была слита в `main` первой командой
   `git merge feature/docs` — конфликтов не было, так как `main` эту строку
   ещё не менял.
2. При попытке слить `feature/reports` командой `git merge feature/reports`
   Git сообщил о конфликте в `README.md`, потому что `main` (уже содержащий
   изменения `feature/docs`) и `feature/reports` изменили одну и ту же
   строку по-разному:

   ```
   <<<<<<< HEAD
   - [x] Отчёты по остаткам — реализован подробный отчёт по низким остаткам

   ## Технологии
   ...
   =======
   - [x] Отчёты по остаткам (команда `report`)
   >>>>>>> feature/reports
   ```

## Как конфликт был исправлен

Конфликт был исправлен вручную:

1. Открыт файл `README.md`, найдены маркеры конфликта `<<<<<<<`, `=======`,
   `>>>>>>>`.
2. Обе формулировки объединены в одну итоговую строку, сохранившую смысл
   обеих версий, а раздел «Технологии» из `main` оставлен без изменений:

   ```
   - [x] Отчёты по остаткам (команда `report`) — показывает товары с остатком ниже минимального порога
   ```

3. Маркеры конфликта удалены, файл сохранён.
4. Файл добавлен в индекс командой `git add README.md`.
5. Слияние завершено командой `git commit`, которая зафиксировала
   merge-коммит `Merge branch 'feature/reports' into main` с исправленным
   конфликтом.

После исправления конфликта запущены тесты (`pytest`) и командная строка
приложения — работа `add`/`remove`/`list`/`report` проверена вручную,
регрессий не обнаружено.
